# 环境依赖与运行示例

## 1. 运行前提

公开脚本不是纯 PyTorch 独立脚本，运行前需要准备与任务代码匹配的外部环境：

| 依赖 | 用途 |
| --- | --- |
| Python | 执行脚本 |
| PyTorch | Student 网络、权重加载和优化 |
| PyYAML | 读取观测配置 |
| Isaac Sim | 仿真应用、相机和物理场景 |
| Isaac Lab | 环境配置、传感器和向量化环境 |
| Gymnasium | 创建任务环境 |
| RSL-RL / `isaaclab_rl` | Teacher checkpoint 加载与向量环境包装 |
| OpenArm task package | 注册 `OpenArm-Bimanual-Box-Stable-Lift-*` 任务 |

版本应与外部 Isaac Lab/OpenArm 工作区保持一致。该公开包没有重新声明版本号，也不应通过盲目执行 `pip install` 替换现有 Isaac Lab 环境。先在目标环境检查导入：

```bash
python -c "import torch, yaml, gymnasium; import isaaclab, isaaclab_rl, isaaclab_tasks, openarm.tasks; print('imports: ok')"
```

如果 `isaaclab` 或 `openarm.tasks` 导入失败，应先按对应外部工程的安装说明配置环境和任务注册，再运行本目录脚本。

## 2. 路径约定

以下命令以公开包根目录为当前目录：

```bash
cd OPEN_SOURCE_ROOT
```

其中：

- 权重：`student/visual/student_final.pt`；
- 观测配置：`student/visual/observation_config.yaml`；
- 脚本：`code/`；
- 输出目录应放在包外或明确的临时目录中，不要把评估结果回写到公开发布包。

## 3. 回放已发布 Student

下面的命令在 Isaac Sim 中创建带前置 RGB 相机的播放任务。`--headless` 可按目标机器的图形环境选择；需要可视化时可去掉该参数。

```bash
python code/play_visual_student.py \
  --task OpenArm-Bimanual-Box-Stable-Lift-Compat-Play-v0 \
  --checkpoint student/visual/student_final.pt \
  --obs_config student/visual/observation_config.yaml \
  --num_envs 1 \
  --headless \
  --real-time
```

回放脚本会检查权重中的 `student_proprio_dim` 与环境 policy observation 维度是否一致。它只加载 Student 权重，不需要 Teacher checkpoint。

## 4. 重新蒸馏 Student

蒸馏需要使用者自己的 Teacher 名义策略和残差策略 checkpoint。两者不会随公开包提供：

```bash
python code/distill_adaptive_residual_visual.py \
  --task OpenArm-Bimanual-Box-Stable-Lift-Compat-v0 \
  --nominal_checkpoint /path/to/private/teacher_nominal.pt \
  --residual_checkpoint /path/to/private/teacher_residual.pt \
  --output_dir /path/to/local/student_distill_run \
  --obs_config student/visual/observation_config.yaml \
  --num_envs 64 \
  --max_iterations 1000 \
  --steps_per_iteration 24 \
  --batch_size 256 \
  --headless
```

脚本会在输出目录生成最终权重、观测配置和蒸馏元数据，并按 `--save_interval` 保存中间 checkpoint。若输出目录已有 `student_final.pt`，需要改用新的输出目录，或显式添加 `--overwrite`。

主要可调参数包括 `--learning_rate`、`--weight_decay`、`--replay_iterations`、`--residual_scale`、`--residual_lift_gate` 和 `--residual_lift_gate_width`。修改这些参数会改变蒸馏过程，应在使用者自己的实验记录中保存完整命令和配置。

## 5. 运行 Student 评估

评估脚本要求 Student checkpoint，以及用于逐帧重推理和动作误差计算的 Teacher 名义/残差 checkpoint：

```bash
python code/evaluate_visual_student.py \
  --task OpenArm-Bimanual-Box-Stable-Lift-Compat-v0 \
  --student_checkpoint student/visual/student_final.pt \
  --nominal_checkpoint /path/to/private/teacher_nominal.pt \
  --residual_checkpoint /path/to/private/teacher_residual.pt \
  --obs_config student/visual/observation_config.yaml \
  --output_dir /path/to/local/student_eval \
  --num_envs 20 \
  --episodes_per_seed 20 \
  --eval_seed 42 \
  --headless
```

评估脚本使用 Student 轨迹滚动，并在对齐时刻由 Teacher 逐帧重推理；输出目录中会生成 `episodes.jsonl` 和 `summary.json`。`--output_dir` 必须不存在，避免覆盖已有结果。公开包不附带任何既有评估数字，使用者生成的结果默认保存在包外。

## 6. 常见检查

1. **输入维度错误**：确认任务注册正确、配置文件包含 `joint_pos`、`joint_vel`、`actions`，且 policy observation 为 50 维。
2. **Teacher 维度错误**：蒸馏或评估时确认 Teacher observation group 为完整特权观测，并检查 Teacher checkpoint 与当前任务配置匹配。
3. **相机错误**：确认启用了相机（脚本会设置 `enable_cameras`），且环境中存在 `front_camera`；相机输出必须包含 RGB。
4. **权重加载错误**：不要把 RSL-RL Teacher checkpoint 当作 Student checkpoint；Student 权重必须包含 `student_state_dict`、`student_obs_normalizer` 和 `metadata`。
5. **结果目录冲突**：为每次运行指定新的 `--output_dir`，并将日志、轨迹和汇总文件置于发布包之外。
